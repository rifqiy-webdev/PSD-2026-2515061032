Judul: Sistem Leaderboard Pemain Berbasis Binary Search Tree

Program ini berfungsi sebagai simulator pengelolaan leaderboard pemain di sebuah game atau kompetisi secara terstruktur dan efisien. Dari sistem ini, user bisa menambahkan data skor, menampilkan urutan skor pemain, menghapus data pemain, serta melihat posisi skor tertinggi maupun terendah. Program ini membantu mempermudah pengelolaan data peringkat pemain dan mempercepat proses pencarian maupun pembaruan skor pada sistem leaderboard.

Program ini menggunakan struktur data Binary Search Tree (BST) untuk menyimpan data skor pemain. Konsep yang digunakan adalah penyimpanan data berdasarkan nilai, di mana data lebih kecil berada di subtree kiri dan data lebih besar berada di subtree kanan. Dengan BST, proses pencarian, penambahan, penghapusan, dan pengurutan data leaderboard menjadi lebih cepat, rapi, dan efisien.
